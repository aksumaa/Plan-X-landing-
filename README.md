# Dream House AI

PlanX — Premium 3D AI Architecture Landing Page

Build a premium, minimal, cinematic landing page for PlanX, an AI architecture platform that turns a user’s idea into a visual 3D home concept.

IMPORTANT

This is a landing page only.

Do NOT build a dashboard.

Do NOT build a SaaS interface.

Do NOT add sidebar navigation.

Do NOT create admin panels.

Do NOT create complex card grids.

Do NOT overload the page with buttons.

The experience should feel like a premium architecture studio website, not an AI dashboard.

VISUAL DIRECTION

Reference the visual quality of:

Apple

Porsche

high-end architectural studios

modern luxury real-estate websites

premium 3D architectural visualization

Overall feeling:

minimal + architectural + cinematic + futuristic + expensive

Use generous whitespace and a very clean layout.

Avoid generic AI aesthetics.

No neon purple gradients.

No excessive glassmorphism.

No random floating UI.

No excessive animations.
